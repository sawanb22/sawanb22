## 🌟 Featured Engineering Projects

### 🛡️ [EvidenceLab — Enterprise AI Research & Document Intelligence](https://github.com/sawanb22/enterprise-AI-research)
> **Stack:** `FastAPI` • `React 19` • `TypeScript` • `PostgreSQL (pgvector)` • `AWS Bedrock` • `FlashRank` • `PyMuPDF`
- **Dual-Mode Architecture:** Combines autonomous multi-source web discovery with high-throughput private enterprise PDF RAG.
- **Two-Stage Retrieval:** Pairs **1024-dimensional pgvector HNSW cosine search** with sub-15ms local **FlashRank ONNX neural cross-encoder reranking** (`ms-marco-TinyBERT`).
- **Zero-Hallucination Citation Gate:** Programmatic normalized substring matching that verifies every LLM citation against raw source text with character-offset provenance before persisting reports.
- **Resilient & Tested:** 41 automated pytest test suites covering RAG synthesis, token quotas, and 1-shot JSON self-repair schemas.
