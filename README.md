### 🚀 Featured Projects

**[EvidenceLab](https://github.com/sawanb22/enterprise-AI-research)** — A dual-mode AI research and document intelligence platform that combines autonomous multi-source web research with private document RAG, built to address hallucination and source-provenance problems in LLM output. It runs a two-stage retrieval pipeline (pgvector HNSW cosine search plus FlashRank cross-encoder reranking) with a citation-verification gate, backed by 41 automated test suites. It reaches 100% citation traceability, around 70% reduction in retrieval noise from reranking, sub-15ms rerank latency, and 99.9% pipeline resilience through immutable run cloning and JSON self-repair.
Stack: Python, FastAPI, React, TypeScript, PostgreSQL (pgvector), AWS Bedrock, SQLAlchemy, PyMuPDF, FlashRank, Tavily

**[RepFlow](https://github.com/sawanb22/repflow)** — A Next.js and TypeScript workout and exercise onboarding platform backed by a Supabase/Postgres schema. It includes a full design system with a runtime-switchable accent color engine, reusable UI components for exercise media and timers, and SQL migrations that define the exercise catalogue and onboarding state.
Stack: Next.js, TypeScript, React, Supabase/Postgres, PostCSS

**[StudySprint](https://github.com/sawanb22/StudySprint)** — A full-stack study productivity app for tracking timed study sessions, tasks, and subjects, with an analytics dashboard. The backend is Django REST Framework with JWT auth, and the frontend is React with Vite, Redux Toolkit for state, and Recharts for the dashboard charts. A Pomodoro-style timer ties sessions to tasks and logs completed sessions back to the API.
Stack: Django REST Framework, React, Vite, Redux Toolkit, TypeScript, Tailwind CSS
